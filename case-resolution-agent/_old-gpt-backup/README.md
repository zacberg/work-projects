# Old GPT backup

Before you delete the old Custom GPTs in ChatGPT, paste each one's **Instructions** (and note
any uploaded knowledge files / configured Actions) into a file here — e.g. `old-engineer-gpt.md`,
`old-analyzer-gpt.md`. Even with the new scope, tone rules, formatting, and guardrails are often
reusable. Once you've confirmed nothing here is needed, this folder can be deleted.
